# CSV Column Clinic

Clean one column of a CSV and review the changes before exporting.

Download `index.html` and open it in a modern desktop browser. Files are processed locally, with no account or network service.

## Example and supported inputs

Load a customer export, select the city column, trim outer whitespace and choose Uppercase. The preview shows up to 20 changed records and the total count. Other field values and the header stay intact. Export is comma-separated UTF-8 with BOM. Quoted commas, escaped quotes and embedded newlines are supported.
